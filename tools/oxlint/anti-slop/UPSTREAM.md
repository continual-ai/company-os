# anti-slop provenance

Vendored from [dmmulroy/anti-slop](https://github.com/dmmulroy/anti-slop) at commit
`446268e5d15baa968eaec669ff65358d36ae6259`.

The upstream project is intentionally designed to be vendored and adapted to a repository's own
standards. The local copy is ignored by Oxfmt and Oxlint so upstream rule implementation details do
not lint themselves; every exported rule is enabled against Company OS source.
