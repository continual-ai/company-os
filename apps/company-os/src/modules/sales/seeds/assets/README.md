# Demo artwork

Original fictional company marks and illustrated avatars for development scenarios. SVG files are
the editable source; PNG files are the upload fixtures used by the app's supported image pipeline.
Both are source-owned, with no third-party logos, portraits, remote downloads, or runtime conversion.

Keep the PNG alongside its SVG when editing artwork. Use the regular asset import helper instead
of embedding fixture paths in UI components. Missing-image records are intentional fallback cases.
